PLANNER PRO DOCENTE 2026
========================

Aplicação web estática de gestão pedagógica para professores, escolas e coordenação.
Stack principal: Exclusivamente Vanilla JavaScript ES6+, HTML5, CSS3, Firebase SDK web e PWA Offline-First.

ARQUITETURA MVC MODERNA & DESACOPLADA
-------------------------------------

O projeto segue o padrão MVC (Model-View-Controller) organizado em camadas desacopladas:

- Model:         js/model.js + js/models/* (Estado global reativo via js/reactive.js)
- Controller:    js/controller.js + js/controllers/* + js/router.js
- Views:         js/views/* (Renderização modular com DocumentFragment e Event Delegation)
- Componentes:   js/components/* (Suíte UI Reutilizável)
- Serviços:      js/services/* (Persistência Híbrida Offline-First & Cloud Sync)

DIRETRIZES DE SEGURANÇA E PERFORMANCE
--------------------------------------

1. Proibição Estrita: É TERMINANTEMENTE PROIBIDO utilizar Node.js, npm/yarn, React,
   Vue, Angular, Bootstrap ou Tailwind. Todo o código é Vanilla JS ES6+ puro.
2. Sanitização XSS: Toda injeção no DOM deve usar escapeHTML() para textos puros e
   sanitizeComLatex() para conteúdos com fórmulas KaTeX.
3. Performance DOM: Usar DocumentFragment em listagens extensas para evitar Layout Thrashing.
4. Desacoplamento Global: Usar EventDelegator (data-action) em substituição a onclick inline.
5. Persistência Offline-First: Utilizar storageService para gravações no IndexedDB e
   syncService para sincronização com o Cloud Firestore.
